TruthLens — Extension Test Page

Load the TruthLens extension in developer mode, then open this page. Badges should appear on every image larger than 200×200 px.

How to verify:
1. Make sure the backend is running at http://127.0.0.1:8000
2. Load the extension/ folder as an unpacked extension in Chrome
3. Open this file in Chrome (File → Open File, or drag to Chrome)
4. Within a few seconds, coloured circular badges should appear on the large images below
5. Hover a badge to see the verdict. Click it to see the detail panel.
6. Click the extension toolbar icon to see per-tab stats.
